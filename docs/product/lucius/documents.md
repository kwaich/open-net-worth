# Documents

The files behind your money end up scattered: a tax form you sent Lucius last spring, the bank
statements you imported, a receipt attached to a transaction, a report Lucius drew for you.
**Documents** shows them all in one place, lets you add the files that belong with them — a
policy, a deed, a payment schedule — and lets you ask Lucius about any of them later.

## Get started

1. Open Documents: in the **Lucius** tab, click **Documents** (top right).
2. Click **Add files**, or drop files onto the panel. PDFs, photos and scans, spreadsheets
   (xlsx, xls, csv) and text files all work.
3. Open a file and set its **year**, or add a note or tags if you like (see below).
4. Click **Ask Lucius** and ask a question — *"what's my deductible?"*,
   *"when does this renew?"*.

Statements you import, receipts on transactions and files on your assets show up here
automatically — you don't add those yourself.

## Open it

- **Computer:** in the **Lucius** tab, click **Documents** (top right). It opens beside the chat,
  so you can keep talking while you look.
- **Phone:** in the **Lucius** tab, tap the folder-with-a-lock icon at the top. It slides up as
  a tall sheet over the chat; swipe it down, tap the chat above it, or tap × to close it.
- **Any other tab:** the chat side panel has the same folder-with-a-lock icon in its header — Documents
  opens over the page; **Ask Lucius** there puts the file in that chat's message, or drag a row onto
  the chat (on a computer).

Documents stays open, on the item you were looking at, if you refresh the page.

Each row in the list has a **⋮** menu — **Rename**, the note, the tags and **Delete** without
opening the item (on a computer it shows when you point at the row). On a phone, tapping outside
the menu just closes it.

An item's page shows the file, then one row of actions — **Ask Lucius**, where it lives
(**Transaction**, **Account**, **Asset**) and **Download** — then your **Note** (once you write
one), its **Details**, your file's **Settings** (year, Private — an asset's file has
Private alone, the same switch as **Lucius can read** on its asset's page) and **Manage** (**Rename**,
**Add a note**, **Delete**). On the phone app,
swipe from the left edge to go back to the list.

## What is in it

| Kind | How it gets there |
|---|---|
| **Uploads** | You add them (**Add files**, or drop files on the panel), or ask Lucius to keep a file you sent in chat |
| **Statements** | Every statement you import, automatically |
| **Receipts** | Every receipt attached to a transaction, automatically |
| **Artifacts** | Reports and charts Lucius made that you chose to keep — **Save** on the artifact in chat |
| **Assets** | Files you attached to a house, a car or a policy in the **Assets** tab, automatically |

Nothing is copied: a statement in Documents is the same statement your account lists. Filter by
kind with the chips at the top, or by one of your tags (they follow the kinds, as **#Apartment**),
or search by name, note or tag.

## Tags

There are no folders — a statement, a receipt or an asset's file already lives somewhere else.
Tags group things instead, across every kind, and one item can have several: tag the payment
schedule, the loan's statements and the deposit receipt **Apartment**, and the **#Apartment** chip
shows them together. On an item's page, **Manage → Add tags** — type one and press Enter (or a
comma), or tap one you already use. Its tags show on its page; tap one to see everything that has
it. Up to 10 per item. Lucius sees them too — "show me everything tagged Apartment".

## Keep a report Lucius made

When Lucius draws a report or chart, its card in the chat has a **Save** button. Saved reports
stay in Documents even if the conversation that made them is cleaned up. Click **Saved** to take
one back out — it stays in its conversation.

You can also just ask him — "save this", or "unsave last week's version". Unsaving takes a report,
or a file you sent in chat, out of Documents without deleting it, so it can be saved again. He
can't remove a statement, a receipt, an asset's file or a file you added straight to Documents:
for those, removing means deleting, and only you can do that, here.

## Uploads

Open a file to set the **year** it is for.
**Download** gets the original file back.

**Rename** gives any item a clearer name — a file on an asset keeps it on the asset's page too.
Clear the name to go back to the automatic one: a file's own name (without its extension — the
full file name stays under **Details**, and a download keeps it), a statement's account and
month, a receipt's transaction. A name never needs an extension. (A saved report or an asset
file always needs a name.)

**Add a note** keeps a few lines of your own on any item — what the file doesn't say: "signed
copy, the original is in the safe", "renews every March", "superseded by the 2027 schedule". It
shows above **Details**, search finds it, and Lucius reads it when you ask about the file. Tap
**Edit note** to change it, or **Remove** to delete it. A note can be up to 1,000 characters.

A PDF — a statement, a receipt, a policy — shows right there: its whole first page, scaled to
fit, with arrows for the other pages. Tap it to read it full size — every page, one under the
other — and pinch (or double-tap; on a computer, double-click or pinch the trackpad) to zoom in;
a photo zooms the same way. A spreadsheet (CSV or Excel)
shows as a small sheet, one tab per sheet — scroll down and the rest of the rows load. Photos show as they are, and a text file — a note, a bank's OFX or QIF export — as its text. A report
Lucius made shows as itself, scaled to fit — tap it to open it full size. Anything else keeps a
preview-sized placeholder — download it to open it.

You can add PDFs, photos and scans, spreadsheets (xlsx, xls, csv) and text files.

- A file you added in Documents lives only there, so removing it **deletes** it. Only you can do
  that — Lucius can't delete these files. (**Settings → Data → Uploaded files** also lists every
  file you've added or attached in chat; **Delete** there removes it for good, including from
  Documents.)
- A file you sent in chat and kept can be **removed from Documents** (it stays in that chat), or
  deleted for good with **Delete file** — then the chat can no longer open or read it either.
- **Delete statement** deletes the statement and its file; the transactions it imported stay in
  your accounts (roll the import back in Accounts to undo those).
- **Delete receipt** deletes the receipt and takes it off its transaction; the transaction stays.
- **Delete file** on an asset file takes it off the asset and deletes it.
- **Open account**, **View transaction** and **Open asset** take you to where each one lives.

## Private

Switch **Private** on for a file Lucius should never read — a will, a passport scan. Lucius can
still see that the file exists, what it is called and your note on it, but every way it has of
reading a file's contents refuses a Private one, even if you ask. You can still open and
download it yourself. Keep anything secret out of a Private file's name and note.

A file on an asset is Private while that asset's **Lucius can read** switch is off — the same
switch, so there is one place to change it. A receipt made from a Private file is Private too. A statement imported from the file before
you marked it Private is part of your statement history, and Lucius can still read that.

Two limits worth knowing:

- Private stops future reads. A conversation that already read the file before you switched
  Private on still contains what it read.
- Private is enforced on Lucius's own tools. **Code execution** (Settings, off by default) runs
  Lucius's scripts in a sandbox that is not a sealed folder, so keep it off if Private matters to
  you.

Only you can switch Private off. Lucius can mark a file Private, never the reverse.

## A statement you added as a file

A statement in **Uploads** — added here, or kept from a chat — is only a file until it is
imported: importing is what books its transactions and lists it under **Statements**. Open it,
click **Ask Lucius** and say "import this statement". Lucius runs the same importer
as the Accounts tab and shows you the rows before anything is booked. (A Private file can't be
imported this way — Lucius can't read it.) The file itself stays in Uploads; delete that copy
once the statement is in, if you don't need both.

## Ask Lucius about a file

Open any item and click **Ask Lucius**. It adds the file to your message as a mention —
then ask your question ("what's my deductible?", "summarise this statement"). Lucius reads the
file when it needs to. You can also type `@` — Documents has its own section — or `@docs` / `@files`
to list them, or just ask: "which documents
do I have from 2025?"

## Troubleshooting

**Lucius says he can't read a file.** It's marked **Private** (or, for an asset's file, that
asset's **Lucius can read** is off). Switch Private off on the file's page if you want him to
read it.

**A file won't preview.** Only PDFs, images, spreadsheets, text files and Lucius's reports
preview here. Click **Download** to open anything else.

**My imported transactions didn't appear when I added a statement here.** Adding a file doesn't
import it. Open it, click **Ask Lucius** and say *"import this statement"* — see
[A statement you added as a file](#a-statement-you-added-as-a-file).
