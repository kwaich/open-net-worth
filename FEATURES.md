# Feature Inventory

This file is retired. It used to hand-maintain a feature list that drifted from reality and
duplicated two better sources of truth — so as of 2026-08-23 it's a pointer instead of a third
copy of the same information:

- **What's known to be broken or deliberately left open**: **[`KNOWN_ISSUES.md`](KNOWN_ISSUES.md)**.
- **What each feature does, for a user**: **[`docs/product/`](docs/product/)** — the same corpus
  that powers the in-app `/help` tab and the public docs site. Every feature page carries an
  honest `status` (`stable` / `beta` / `coming-soon`).
